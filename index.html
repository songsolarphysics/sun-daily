    How it is made
    
    
    Every night a job draws one data source from a pool, then an event or observation from a
    catalogue: flares from the Heliophysics Event Knowledgebase, high-cadence Solar Orbiter
    sequences from the archive's own file list. It downloads the science-level files, not
    browse images, and renders them with a single intensity scaling for the whole sequence, so
    what brightens in the clip brightened on the Sun.
    
    
    Each clip keeps its request on record. “Get the data” gives the commands that fetch the
    same files again.
    
  
    

    


    
  
    Data: NASA/SDO and the AIA science team; ESA and NASA/Solar Orbiter and the EUI team.
  Events: Heliophysics Event Knowledgebase. De-jittering: solar_align.
